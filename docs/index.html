Multi-Agent Architecture

One orchestrator coordinates three specialized sub-agents. Each has one job and the right model for it.

🧠

Orchestrator

gemini-2.5-flash

Handles strategy, brand angle selection, DM pitches, brand post, and content calendar. Coordinates all sub-agents.

📈

TrendResearchAgent

gemini-2.5-flash

Scrapes live data from TikTok, Instagram, and LinkedIn via Apify. Returns ranked trends with opportunity scores.

🎯

InfluencerAgent

gemini-2.5-flash

Scrapes real creator profiles and scores each one on niche fit. Returns ranked matches with why_good_fit explanations.

✉️

EmailAgent

gemini-2.5-flash

Writes a complete customer email — subject, body, CTA — from trend context. Orchestrator never touches the copy.

Quick Start

Two API keys, one command.

bash
# Install dependencies
pip install -r requirements.txt

# Add your API keys
cp .env.example .env
# GEMINI_API_KEY  → aistudio.google.com (free)
# APIFY_API_TOKEN → apify.com (free tier)

# Run a campaign
python main.py \
  --industry food \
  --brand-name "Forkly" \
  --brand-description "Fun meal kit brand for millennials and Gen Z" \
  --platform TikTok \
  --tone "casual, witty"
